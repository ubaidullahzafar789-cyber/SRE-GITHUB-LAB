# SRE-GITHUB-LAB



\# Student Task Tracker



\## Overview

Student Task Tracker is a simple system that helps students manage their coursework tasks. Students can add tasks, view saved tasks, and mark completed tasks. It helps students organize their academic work and manage their time effectively.



\## Scope

\- In scope: Add a coursework task with a title.

\- In scope: Display all saved tasks.

\- In scope: Mark a task as complete.

\- Out of scope: Fee payments.

\- Out of scope: Automatic grading.



\## Stakeholders

\- Student: Records tasks and checks their progress.

\- Instructor: Monitors students' task requirements and academic progress.

\- Project Maintainer: Manages project documentation and maintains the system requirements.



\## Functional Requirements

\- FR-01: The system shall allow a student to create a task with a title.

\- FR-02: The system shall display all saved tasks.

\- FR-03: The system shall allow a student to mark a task as complete.



\## Nonfunctional Requirements

\- NFR-01: The task list shall appear within 2 seconds with 100 saved tasks in at least 95 out of 100 trials on an agreed test device.

\- NFR-02: Every task action shall be accessible using only a keyboard.



\## Acceptance Criteria

\- FR-01: When a student enters the title "Read Chapter 1" and saves it, the task shall appear in the task list.

\- FR-02: When two tasks are saved, opening the task list shall display both task titles.

\- FR-03: When a student marks an incomplete task as complete, its displayed status shall change to Complete.



\## Assumptions and Open Questions

\- Assumption A-01: Students will have access to a computer or mobile device.

\- Question Q-01: Should students be able to set deadlines and receive reminders for their tasks?

\- Question Q-02: Which device will be used to test NFR-01?
